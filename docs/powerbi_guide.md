# Power BI Guide

Use the Gold-layer outputs as the source for the report. Recommended visuals:

- KPI cards for vehicle count, average speed, fuel consumption, and health score
- time-series charts for engine temperature and battery voltage
- route summaries by route ID
- anomaly tables sorted by severity
- map visuals for live fleet movement

Power BI should connect to curated Gold tables rather than raw telemetry so the dashboard stays stable and easy to explain.
